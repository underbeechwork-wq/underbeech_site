# 植木屋 アンダービーチ 移植版 v7（日本語中心版）

若い層・初めて植木屋へ依頼する人が「頼みやすい」と感じる方向へデザインを調整したデモです。

## v7の主な変更
- キャッチコピーを「庭のこと、もっと気軽に。」へ変更
- 最初の画面に「料金を見る」「写真で相談」の2つの案内ボタン
- 「見積もりだけでも大丈夫 / 庭木1本から大丈夫 / 相談無料」を明示
- 料金を連絡前に確認できることを強く訴求
- 丸みのあるカード・明るいグリーン・余白を使った若い印象へ変更
- スマホ下部の固定案内ボタンを「料金をチェック / 写真で相談」に変更
- 問い合わせ欄を「まだ依頼を決めていなくても大丈夫」という雰囲気へ変更
- 既存の料金シミュレーター・施工事例管理・検索向け設定は維持

`index.html` をブラウザで開いて確認できます。

※デモの問い合わせフォームは実送信しません。

- 英語だったメニュー・見出し・施工前後ラベルを日本語へ変更
- ロゴ表示も「植木屋 アンダービーチ」を中心に整理


## v8 変更点
- ヘッダーのナビゲーションをボタン型に変更
- 各項目に補足文を追加し、ぱっと見で内容が伝わるよう改善
- 「料金の目安」「お問い合わせ」を強調表示
- スクロール位置に応じて現在地が分かるアクティブ表示を追加
- モバイルメニューもカード型にして押しやすさを改善

- Google検索を許可
