# 植木屋 アンダービーチ 公開サイト（v17）

**v17はレスポンシブ表示の仕上げ版です。** v16の画面幅対策に加え、超横長PC・タブレット横向き・小型スマホ・高さの低い画面でも、余白や文字サイズ、カードの密度が自然に見えるよう調整しています。モバイルメニューの背景スクロール防止、Escキー対応、フォーカス表示など操作性も改善しています。

正式URL: https://underbeech.com/

## v15の主な変更
- 公開サイトに残っていたデモ管理画面と localStorage 編集機能を削除
- JavaScriptから title / meta description を書き換える処理を削除し、SEO設定をHTML側に固定
- トップページを短く整理し、「料金 → 作業内容 → 施工事例 → 流れ → 事業者情報 → 対応エリア → お問い合わせ」の順に整理
- ヘッダーを簡素化
- スマホ下部を「料金を見る / 電話する」に変更
- 未接続の問い合わせフォームを公開画面から外し、実際に使える電話窓口を明確化
- 写真送信機能が未接続のため「写真で相談できます」という断定表現を一時的に削除
- 施工実績は実際のものだけ掲載する方針を明記
- さいたま市の区名と東京都北区を区別しやすく調整

## GitHubへ更新するとき
ZIPの中身をリポジトリ直下へ上書きしてください。CNAME は削除せず `underbeech.com` のまま使います。

### 手動で削除するファイル
以前アップロードされた文字化けファイル `譁ｽ蟾･莠倶ｾ玖ｿｽ蜉繧ｬ繧､繝・md` は、上書きアップロードだけでは消えません。GitHub上で削除してください。
